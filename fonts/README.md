# Fuentes incluidas

Todas bajo la SIL Open Font License 1.1 (redistribuibles; ver cada `OFL-*.txt`). Origen: github.com/google/fonts.

| Archivo | Uso en estilos |
|---|---|
| `PlayfairDisplay.ttf`, `PlayfairDisplay-Italic.ttf` | `luxury`, `luxury-italic`, títulos del tercio inferior |
| `CormorantGaramond.ttf` | `champagne` (subtítulos) |
| `Cinzel.ttf` | `noir` |
| `Montserrat.ttf` | `modern`, subtítulo del tercio inferior |

Son fuentes variables (eje de peso); el estilo fija el peso. El estilo `classic` usa DejaVu Sans Bold del sistema (`fonts-dejavu-core`).
