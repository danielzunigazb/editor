# Iconos SVG

Conjunto curado de **Lucide** (https://lucide.dev, licencia ISC; ver `LICENSE-lucide.txt`), descargado de
`github.com/lucide-icons/lucide/icons/`. Son iconos de trazo con `stroke="currentColor"`: el editor los tiñe con el color
del tema (o el que se pida) antes de rasterizarlos al tamaño exacto de exportación.
Los garabatos (`doodle-*`) no son SVG: los dibuja `icons.py` con las primitivas de trazo a mano de `sketch.py` (propios, CC0).
